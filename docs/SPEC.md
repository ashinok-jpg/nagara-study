# ながら勉強アプリ 仕様書

家事やテレアポをしながら勉強するためのスマホアプリ（Expo SDK 58 / expo-router）。
教材ファイルを取り込むと、**数十秒で読める短いカード**に自動で区切り、**数分おきに1枚**届ける。カードを読んだら**すぐにテスト**が出る。

- 想定シーン：片手がふさがっている／耳か目のどちらかしか空いていない／いつ中断されるかわからない
- だから「1画面1つのこと」「大きいボタン」「無視しても怒らない（通知を連打しない）」を守る
- 問題はAIを使わず、**ルールで自動作成**する（オフライン・無料）

---

## 1. 全体の流れ

```
取り込み（ファイル or 貼り付け）
  → 正規化 → ブロック分割 → 文分割 → 詰め込み → カード（Chunk）
  → 問題生成（Question）
  → 教材（Deck）として端末に保存

ながら勉強セッション：
  [カード表示] → 「読んだ」 → [テスト 1〜2問] → [結果] → [待機（カウントダウン）] → 通知 → [カード表示] …
```

---

## 2. 区切りルール（chunker）

### 2.1 長さ（区切りの長さ設定）

文字数は「表示される文字」から空白とマーカー記号（`**` など）を除いて数える。

| 設定 | 最小 min | 目標 target | 最大 max | 読む時間の目安 |
|---|---|---|---|---|
| 短め `short` | 60 | 100 | 120 | 約15秒 |
| 標準 `normal`（既定） | 120 | 180 | 220 | 約30秒 |
| 長め `long` | 220 | 320 | 400 | 約1分 |

- 根拠：ながら読みは集中して読むときより遅いと考え、日本語で毎分360字程度を想定。
- **英語主体のテキスト**（ASCII文字が70%以上）は min/target/max をすべて **2.5倍** にする（英語は1語あたりの文字数が多いため）。

### 2.2 正規化

1. BOMを除去し、改行コードをLFにそろえる。タブは半角スペースにする。
2. 各行の末尾の空白を削る。
3. 3行以上続く空行は1つの空行にまとめる。

### 2.3 ブロック分割（行単位）

上から順に判定し、最初に当てはまったものを採用する。

| 種類 | 判定（行頭） | 扱い |
|---|---|---|
| 見出し | `#`〜`######` + 空白／`第◯章・節・編・部・講・回`／行全体が `【…】`／`■□◆◇●▼▶` で始まる／`1.` `1.2` `1)` で始まり30字以下で「。」を含まない行 | **本文にしない**。以降のカードの `heading` になる。見出しが変わったら、その時点でカードを必ず閉じる |
| Q&A | `Q:` `Q：` `Q1.` `問:` `問：` の行と、続く `A:` `A：` `答:` `答：` の行 | Q行とA行を合わせて**分割できない1単位**にする |
| 箇条書き | `- ` `* ` `・` `①〜⑳` `1.` `1)` `（1）` が連続する行 | 1項目＝1単位。項目の途中では切らない |
| 用語行 | `語：説明` / `語: 説明`（語は20字以下） | 1行＝1単位 |
| 表 | `|` で始まる行 | 1行＝1単位。区切り行 `|---|` は捨てる |
| 段落 | 上のどれにも当てはまらない行 | 空行までを1段落とし、2.4で文に分ける |

見出しが入れ子のとき（`#` の下に `##` があるなど）、`heading` は `第1章 ＞ 1.2 細胞` のように親子を「 ＞ 」でつなぐ。

### 2.4 文分割（段落の中）

- `。！？!?` の直後で切る。英語は `. ` `! ` `? ` の直後で切る。
- 括弧 `「」『』（）()【】` の中では切らない。
- 句点のすぐ後ろの閉じ括弧（`。」` など）は前の文に含める。

### 2.5 詰め込み（文や単位をカードにまとめる）

単位（文・Q&A・箇条書きの項目・用語行・表の行）を先頭から順に足していく。

1. 次の単位を足しても **max 以下**なら足す。
2. 足すと max を超える場合：
   - 今のカードが **min 以上**ならカードを閉じ、その単位から新しいカードを始める。
   - min 未満なら、足して **max × 1.3 以下**になるときだけ足す（短すぎるカードを作らない）。それも超えるならカードを閉じる。
3. 今のカードが **target 以上**で、次の単位が新しい段落の始まりなら、そこでカードを閉じる（段落の切れ目を優先する）。
4. 見出しが変わったら必ずカードを閉じる。
5. 同じ見出しの最後のカードが **min の半分未満**なら、直前のカードとつないでも max × 1.3 以下になる場合に限りつなぐ。

### 2.6 長すぎる単位

1つの単位が max を超える場合は、`、，,;；` の直後で切る。それでも長い場合は max の位置で強制的に切る。ただし `**…**` などマーカーの途中では切らない。

### 2.7 カードに持たせる情報

`id`（`c0001` から連番）、`index`、`heading`（直前の見出しを親子でつないだもの。見出しがなければ null）、`text`（マーカーを残した本文。単位どうしは改行でつなぐ）、`charCount`。

## 3. 問題作成ルール（questionGen）

1枚のカードから**最大2問**、できれば**最低1問**作る。下の優先順位の上から順に候補を探し、出どころ（`source`）が違うものを優先して選ぶ。

### 3.1 候補の探し方（優先順）

| 優先 | source | 見つけ方 | 問題 |
|---|---|---|---|
| P1 | `marker` | 本文中の `**語**`、行の途中にある `【語】`、`〔語〕` | その語を含む文の、その語の部分を `（　　　）` にした穴埋め。答え＝語 |
| P2 | `qa` | Q&A単位 | 問題＝Q、答え＝A |
| P3 | `glossary` | 用語行 `X：Y` | 「Y」に当てはまる用語は？（Yが60字を超える場合は60字で切って「…」を付ける）。答え＝X |
| P4 | `definition` | `X とは[、,]? Y（である／のこと／をいう／を指す／です／だ）。`（Xは1〜20字） | 「Xとは？」。答え＝Y（思い出す問題）。または X の部分を穴埋め |
| P5 | `number` | 数字＋単位（年・月・日・%・％・人・円・個・回・倍・km・m・kg・g・℃・世紀・歳・時間・分・秒） | 数値の部分を穴埋め |
| P6 | `term` | `「語」`（2〜15字）／3字以上のカタカナ語／2字以上の英大文字の略語 | 穴埋め |
| 最後の手段 | `fallback` | どの候補もない | 「このカードの要点は？」（見出しがあれば見出しも出す）。答え＝カードの最初の文。自分で○×をつける |

### 3.2 問題の形式

- **4択 `choice`**：穴埋めで、同じ教材の中から**同じ種類のハズレ選択肢を3つ以上**集められるとき。
  - ハズレ選択肢は、教材全体の同じ `source` の答え（数値なら同じ単位の数値）から選ぶ。
  - 答えと同じもの、答えを含むもの、答えに含まれるものは除く。
  - 文字の種類（カタカナ／漢字／英数字）と長さが近いものを優先する。
  - 数値で集まらないときは、答えの数値を少しずらした値（±1、±10%、年なら±数年など）で補う。
- **○× `truefalse`**：P1／P4の穴埋めのうち約30%を、ハズレ選択肢に入れ替えた**間違いの文**にする（答えは「×」、`correction` に正しい文）。残りは4択か思い出す問題にする。
- **思い出す `recall`**：選択肢が作れないとき。答えを見て、自分で「覚えてた／忘れてた」を選ぶ。

### 3.2.1 実装で追加したルール（2026-11-08、実際の問題の質を見て調整）

- ○×は約40%を**正しい文（答え○）**にする（すべて×だと「×を押せば当たる」ため）。
- 2問目は出どころ違いを優先するが、P6（カタカナ語など）より、P1（太字）の2問目を優先する。
- 答えが問題文の別の場所に出ている穴埋めは作らない。2問目の答えが1問目の文に出ている場合も作らない（答えがバレるため）。
- 4択のハズレ選択肢は同じ出どころから選び、足りなければ他の「語」の答えで補う。数値の4択は、本文中の数値を最大2個使い、残りは値をずらして作る。用語行（P3）も、ハズレ選択肢が足りれば4択にする。
- 番号付きの行は、前後にも番号付きの行が続いていれば箇条書き、単独なら見出しとして扱う。`■●` で始まる行は、40字以下で「。」を含まないときだけ見出しにする。
- 段落の中で「。」も「、」もなく終わる行は、そこで1文が終わったとみなす（ノートは「。」を省くことが多いため）。
- 長すぎるQ&Aは分割しない。「、」で切った単位どうしは改行を入れずにつなぐ。

### 3.3 再現性

並べ替えや30%の抽選などの乱数は、**教材の本文から作ったハッシュをシードにした擬似乱数**を使う。同じファイルからは毎回同じ問題ができる（テストしやすくするため）。

## 4. ながら勉強セッションのルール

- **間隔**：1・2・3・5・10分から選ぶ（既定3分）。
- **1サイクル**：カード → 「読んだ」 → 即テスト（そのカードの問題1〜2問）→ 結果 → 待機。
- **通知**：1サイクルが終わった時点で、`今＋間隔` に**ローカル通知を1回だけ**予約する（「次のカードが届きました」）。繰り返しの通知は使わない。**反応しなければ次の通知は来ない**（電話中に通知が鳴り続けないようにするため）。通知をタップするとセッション画面が開く。
- **アプリを開いているとき**：カウントダウンが0になったら、振動とともに次のカードを自動で表示する。
- **「今すぐ次へ」**ボタンで待たずに進める。**「一時停止」**で予約中の通知を取り消す。
- **復習**：間違えた問題は復習キューに入れ、**3枚後**にもう一度出す（カードのテストの後に追加）。正解したらキューから外す。
- **読み上げ**（設定でオン／オフ、速度も選べる）：カード本文と問題を `ja-JP` で読み上げる。マーカー記号は読まない。
- **進捗**：教材ごとに「次のカード番号・問題ごとの正解数と不正解数・復習キュー」を保存する。最後まで行ったら「1周しました」と表示し、最初からやり直すか、間違えた問題だけ出すかを選べるようにする。

## 5. ファイルの受け渡し（取り込み）

- **ファイルを選ぶ**：端末の「ファイル」アプリ・Googleドライブ・OneDrive などから `.txt` `.md` `.csv` を選べる（expo-document-picker）。複数選択可で、1ファイル＝1教材。
- **テキストを貼り付け**：コピーした文章をそのまま貼れる。
- 取り込む前に、カードの枚数・最初の数枚・作られた問題の例を**プレビュー**で確認できる。区切りの長さもその場で変えられる。
- **書き方のコツ**を取り込み画面に表示する：重要な語を `**太字**` で書くと問題になる、`語：説明` の形で書くと用語問題になる、`Q:` と `A:` で書くとそのまま問題になる、`#` で見出しをつけるとカードがきれいに区切られる。
- PDF と Word は今回は対象外（端末内での文字の取り出しが不安定なため）。テキストに書き出してから取り込む。

## 6. 画面

| パス | 画面 | 内容 |
|---|---|---|
| `/` | ホーム | 教材の一覧（タイトル・進み具合・正答率）、大きな「続きから」ボタン、「＋教材を追加」 |
| `/import` | 取り込み | ファイルを選ぶ／貼り付け、タイトル、区切りの長さ、プレビュー、保存、書き方のコツ |
| `/deck/[id]` | 教材の詳細 | カードの一覧と各カードの問題数、開始、進捗のリセット、削除 |
| `/session/[id]` | ながら勉強 | カード → テスト → 結果 → 待機のくり返し |
| `/settings` | 設定 | 間隔、読み上げのオン／オフと速度、振動、区切りの長さの既定値 |

UIの原則：文字は大きく（本文18pt以上）、操作ボタンは画面の下半分に置き、高さ56pt以上にする。1画面でやることは1つだけ。ダークテーマ。
