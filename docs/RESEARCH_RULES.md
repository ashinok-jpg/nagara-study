# 教材リサーチルール（ながら勉強アプリ用）

このルールは「ながら勉強」アプリに取り込む教材を、リサーチして作るためのものです。
人間・Claude・Deep Research（ChatGPT／Gemini など）の誰が作っても、同じ品質の教材になることを目指します。

---

## 1. 共通ルール

### 1.1 情報源

| 順位 | 情報源 | 使い方 |
|---|---|---|
| A | 公的機関・国際機関・業界団体の資料（政府統計、SEMI、SIA、WSTS など）、企業の公式IR・プレスリリース、学術書・教科書、大学・博物館の解説 | **数字・年号・固有名詞はAで確認する** |
| B | 大手報道（日経、Reuters、Bloomberg など）、専門メディア | 最新動向の確認。Aで確認できない場合は2つ以上のBで照合する |
| C | Wikipedia、まとめサイト、個人ブログ、AIの回答 | **入口として使うだけ**。Cだけを根拠に書かない |

- **年号・数字・人名・地名は、2つ以上の情報源で照合する**。食い違ったら、教科書や公的資料の値を採用し、出典ファイルに「異説あり」と書く。
- **変わりやすい情報**（市場シェア、売上、最先端の製造プロセス、規制など）には、本文の中に「2025年時点」のように**時点を書く**。
- 確認できなかったことは書かない。「〜と言われる」のような、ぼかした書き方で逃げない。

### 1.2 書式（アプリが問題を作れる形）

アプリは本文の書き方を手がかりに問題を作ります（docs/SPEC.md 3章）。次の形で書いてください。

1. **見出し**：`#` で大きな単元、`##` で小さな単元にする。`##` 1つで、カード3〜6枚分（約600〜1,000字）が目安。
2. **段落**：1段落は2〜4文。1文は60字以内にする。空行で段落を区切る。
3. **太字**：その段落で一番大事な語を `**語**` で囲む（1段落に1〜2個）。
   - 太字にした語が、同じ文の中にもう一度出てこないようにする（答えが見えてしまうため）。
   - 太字にするのは、名詞の語（人名・用語・地名・出来事の名前）。文や長い句は太字にしない。
4. **定義**：大事な概念は `〇〇とは、△△である。` の形で1文で書く。
5. **数字**：年・%・nm などの単位を必ず付ける（例：`1789年`、`約60%`、`3nm`）。
6. **用語集**：各 `##` の最後に、用語を3〜5個、`用語：説明` の形で1行ずつ書く（説明は60字以内）。
7. **確認問題**：各 `##` の最後に、`Q:` と `A:` の組を2個書く。Aは短く（1語〜1文）。
8. **禁止**：表、画像、URL、脚注、出典の表記（`[1]` など）を本文に入れない。出典は別のファイルに書く（1.3）。

### 1.3 ファイル

- 1ファイル＝アプリの教材1つ。**5,000〜8,000字**（標準の区切りで、カード25〜45枚程度）。
- 置き場所：`materials/<テーマ>/NN-<名前>.md`
- 出典は `materials/<テーマ>/SOURCES.md` に、ファイルごと・見出しごとにまとめる（URL・資料名・確認した日付）。

### 1.4 品質チェック（取り込む前に必ず通す）

`npx jest src/__tests__/materials.test.ts` を実行すると、`materials/` の全ファイルをアプリと同じエンジンでカードと問題に変換して検査します。

- すべてのカードに問題が1問以上ある
- 「思い出す（最後の手段）」の問題（fallback）が、全体の10%以下
- 問題文に答えが出てしまっている問題がない
- カードの文字数が、標準の区切りの範囲（120〜220字。やむを得ない場合でも286字以下）に収まっている

あわせて、生成された問題を人の目で読み、**勉強として意味のある問いになっているか**を確認する。

## 2. テーマ別ルール

### 2.1 世界史

- **レベル**：高校世界史（世界史探究）の通史。教養として、大きな流れを説明できるようになることが目標。
- **範囲と分け方**（1ファイル＝1時代）：
  1. 古代文明とギリシア・ローマ
  2. アジアの古代帝国（中国・インド・イスラームの成立まで）
  3. 中世（ヨーロッパ封建社会・イスラーム世界・モンゴル帝国）
  4. 近世（大航海時代・宗教改革・主権国家・アジアの帝国）
  5. 近代（市民革命・産業革命・国民国家・帝国主義）
  6. 現代（二つの世界大戦・冷戦・冷戦後）
- **書き方の重点**：
  - 「なぜ起きたか → 何が起きたか → 何が変わったか」の順で書く。年号の羅列にしない。
  - 年号は「覚える価値のあるもの」だけ。1つの `##` に3〜5個まで。
  - 地域どうしのつながり（交易・戦争・思想の伝わり方）を書く。
- **確認の重点**：年号・人名の漢字表記・王朝名は、教科書または大学・博物館の解説で確認する。

### 2.2 半導体

- **レベル**：仕事で半導体業界の話についていけるビジネス教養。理系の専門知識がなくても読めるようにする。
- **範囲と分け方**：
  1. 半導体のしくみ（導体と絶縁体、シリコン、トランジスタ、集積回路、ムーアの法則）
  2. 種類と用途（ロジック・メモリ〔DRAM／NAND〕・アナログ・パワー半導体・センサー）
  3. 製造工程（設計、前工程〔ウェハ・露光・エッチング・成膜〕、後工程〔パッケージング・テスト〕）
  4. 業界の構造と主要企業（IDM・ファブレス・ファウンドリ・OSAT、製造装置・材料、日本企業の強み）
  5. 最新動向と地政学（AI向け半導体、先端パッケージ、各国の補助金と輸出規制、日本の新しい工場、2026年時点の状況）
- **書き方の重点**：
  - 専門用語は、初めて出てきたときに「〇〇とは、△△である。」で定義する。
  - 例えを1つ添える（例：露光＝回路の写真を焼き付ける）。
  - 企業の売上・シェアは時点と出典の種類を書く（例：「2025年の売上高で」）。
- **確認の重点**：数字・シェア・プロセスの世代・補助金額は、企業の公式発表・業界団体・政府資料で確認する。**最新動向の章は、確認した日付を SOURCES.md に必ず書く**。

## 3. Deep Research にそのまま貼るプロンプト

`{テーマ}` と `{範囲}` を書き換えて使う。

```
あなたは教材ライターです。スマホの「ながら勉強」アプリに取り込む学習教材を、日本語のMarkdownで作ってください。

【テーマ】{テーマ}
【範囲】{範囲（例：近代 — 市民革命・産業革命・国民国家・帝国主義）}
【レベル】{世界史：高校世界史の通史／半導体：理系でない社会人向けのビジネス教養}
【分量】本文 5,000〜8,000字

【情報源のルール】
- 年号・数字・人名・地名は、2つ以上の信頼できる情報源（公的機関、教科書、企業の公式発表、大手報道）で照合する。Wikipediaだけを根拠にしない。
- 市場シェアや最先端の技術など変わりやすい情報には「2025年時点」のように時点を書く。
- 確認できなかったことは書かない。

【書式のルール（厳守）】
- 「#」で大きな単元、「##」で小さな単元。「##」1つは600〜1,000字。
- 1段落は2〜4文、1文は60字以内。段落は空行で区切る。
- 各段落で一番大事な語（名詞）を **太字** にする（1段落に1〜2個）。太字の語は同じ文の中で繰り返さない。
- 大事な概念は「〇〇とは、△△である。」の1文で定義する。
- 数字には必ず単位を付ける（1789年、約60%、3nm など）。
- 各「##」の最後に、用語を3〜5個「用語：説明」の形で1行ずつ（説明は60字以内）。
- 各「##」の最後に、確認問題を「Q: 〜」「A: 〜」の形で2組（Aは短く）。
- 本文に表・画像・URL・脚注・[1]のような出典番号を入れない。

【出力】
1. 教材本文（上の書式のMarkdown）
2. 最後に「---」で区切って「出典」：見出しごとに、使った資料名とURLと確認日
```
